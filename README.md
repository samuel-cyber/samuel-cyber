## 🚀 Featured Projects

### 🐝 [Sentinel Swarm](https://github.com/samuel-cyber/SentinelSwarm)

**AI-powered autonomous bug discovery and repair system.**

Four specialized IBM Bob 2.0 agents analyze a codebase, generate adversarial tests, identify bugs, produce patches, and verify the fix with the **same test** before reporting it.

The core idea is simple: **don't claim a bug unless you can prove it.**

**Stack:** `Python` `Flask` `pytest` `Docker` `IBM Bob 2.0`

🏆 Built in 48 hours for the **IBM Bob 2.0 Hackathon**

---

### 💼 [Hustle OS](https://github.com/samuel-cyber/Hustle-Os)

**WhatsApp-native financial infrastructure for Nigeria's informal businesses.**

Hustle OS turns natural-language WhatsApp transactions into structured financial data, generating a **Business Passport** with risk tiers and recommended credit limits while providing an AI financial copilot for business owners.

**Stack:** `FastAPI` `React` `PostgreSQL` `Supabase` `Twilio` `Claude` `Framer Motion`

🔗 [Live Demo](https://hustle-os-1-vrsq.onrender.com)

---

### 🌊 [Riparia](https://github.com/samuel-cyber/riparia-api)

**AI-supported validation middleware for citizen freshwater ecosystem observations.**

Riparia takes citizen-submitted photos and descriptions, evaluates them against published ecological indicators, routes observations through **human review**, and converts approved observations into standards-compliant **HL7 FHIR Observations**.

**Stack:** `Python` `FastAPI` `PostgreSQL` `Gemini Vision` `Cloudflare R2` `HL7 FHIR` `Render`

🌍 Built for the **OneAquaHealth IEEE Global Hackathon**

---

### 🩺 [Breast Cancer KNN Classifier](https://github.com/samuel-cyber/knn-breast-cancer-classifier)

**K-Nearest Neighbors implemented entirely from scratch with NumPy.**

No scikit-learn. The project implements distance calculation, nearest-neighbor selection, majority voting, feature standardization, and evaluation metrics from first principles.

**Results:** `98.2% Accuracy` · `100% Precision` · `90.48% Recall` · `95% F1`

**Stack:** `Python` `NumPy` `Pandas` `Matplotlib`

> Built to understand the algorithm rather than hide behind the library.
